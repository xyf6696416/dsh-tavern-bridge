# 去 AI 味的中文叙事笔法

## 一句话

**AI 味的根源不是词汇，是「每一句都在解释」。**
人写东西是**指着东西说**，AI 写东西是**描述自己在指什么**。

判据只有一个：把这段念出来，像不像有人在跟你讲事。像报告、像说明书、像翻译小说，就是 AI 味。

**最核心的一条**：不写「感受」，写「后果」。

| 抽象 | 换成 |
|---|---|
| 她很羞耻 | 她想挡脸，手举到一半又放下 |
| 很多 | 第五管推不进去了 |
| 很深 | 脖子上凸出一圈轮廓 |
| 很久 | 二十多分钟，中间停过两次 |
| 很爽 | 脚趾蜷起来，小腿肚子抽了一下 |

每一个抽象词都要换成一个能被看见的物理事实。换不出来，这句还没写完。

### 判断原则

- **宁可多判一份，不要漏判一份。** 漏读的代价是重写一整轮，多读一份只多几秒。
- **道具、亲密、足交这三类常常互相叠加**，别只挑一个就走。
- `00` 和 `01` 几乎每轮都命中，别跳。
- 判完就停，不要读完之后再回头补判一轮。

## 最小可用规则（不读文件也能照着写）

如果时间紧或不想读参考文件，**只守住这六条**，效果已经能到七成：

1. **平均句长 ≥ 30 字**。低于 30 字就是电报体。段落可以短，**句子必须有长的**。
2. **不写「她感到 XX」**。改成身体动作：手放哪、眼睛看哪、呼吸什么样。
3. **一个动作至少写 300 字**（亲密场景）。拆成五拍：预备 / 接触 / 推进 / 反应 / 停留。
4. **器官一律用原名，一个代称都不留。** 见下面那张表 —— 这是最容易被忽略、也最伤画面的一条。
5. **每个动作句都要有「谁 + 做什么 + 对谁」。** 缺受力方的句子必然模糊。
6. **结尾停在一个动作上**，不总结、不升华、不回望。

### 第 4 条的落地：代称清零

**这是全局规则，和任何题材叠加** —— 只要正文里出现身体部位就适用。
完整词表、禁用清单、动词模糊、固定句式、自检流程都在 → **`references/00-器官原名.md`**

不读文件也要记住这四条：

1. **禁用词**：那里 / 那处 / 那个地方 / 最敏感的地方 / 前端 / 底部 / 深处 / 那道 / 那根 / 它
2. **换成什么**：龟头、冠状沟、马眼、系带、阴茎体、棒身、根部、阴囊、睾丸、会阴；阴唇、阴蒂、小穴、宫口、子宫
3. **动作句要齐三样**：谁 + 做什么 + 对谁（缺受力方必然模糊）
4. **代称破坏力按出现算，不按比例算 —— 留一个就破一个画面**

**同义词轮换也是代称。** 同一个词可以连着用三次；为了「不重复」换个说法，比重复更像机器。

## 三条最容易踩的坑

**坑一：把「段落切碎」做成「句子切碎」。**
段落短 + 句子长 = 有节奏；段落短 + 句子也短 = 分镜脚本。
判断法：两句话用逗号连起来读得通，就本来该连起来。

**坑二：矫枉过正写成全是长句。**
句长均值冲到 45 字以上、短句只剩几个百分点，读起来喘不上气，像翻译小说。
目标是**参差**，不是「一律长」。短句是用来刹车的。

**坑三：为了「不重复」换同义词。**
这是最像 AI 的习惯。参考文本里最高频的名词用了 238 次。
**换个说法来回避重复，比重复本身更像机器。**

## 边界

- 不改变角色卡 / 世界书规定的**输出格式、标签、变量结构** —— 那些优先
- 不改动既定剧情走向与人物设定
- 成人 / 暴力等题材的边界由角色卡与平台规则决定，本技能只管**怎么写**，不管**写什么**
- 思维链不受此约束，思维链可以正常分析推理
