# 手法库 —— 十五条具体写法

> 这是本技能最核心的一章。规则告诉你「不要写什么」，这里告诉你「该写什么」。
> 写卡住的时候，随机抽一条硬套上去。
>
> **写身体部位时，先读 `00-器官原名.md`**（全局规则，这里不重复）。

---

## 用一个公式兜底

十五条其实就是一件事：

> **不写「感受」，写「后果」。**

| 抽象 | 换成 |
|---|---|
| 她很羞耻 | 她想挡脸，手举到一半又放下 |
| 很多 | 第五管推不进去了 |
| 很深 | 脖子上凸出一圈轮廓 |
| 很久 | 二十多分钟，中间停过两次 |
| 很爽 | 脚趾蜷起来，小腿肚子抽了一下 |
| 很累 | 站不住，顺着墙滑下去坐着 |

**每一个抽象词，都必须换成一个能被看见的物理事实。**
换不出来，就说明这句还没写完。

---

## 手法 1：物件要有「履历」，不是「名称」

不要写「一双鞋」「一条丝袜」。要写它**今天经历了什么**。

- 差：`她穿着白丝袜。`
- 好：`白丝袜穿了三天，足跟处被鞋磨出一小块毛，脚趾那儿有洗不掉的灰。`

**操作**：第一次提到某个物件时，给它三样东西 —— **材质、磨损、今天的状态**。
之后每次再现，让它**变一点**（湿了 / 粘了 / 破了 / 变形了 / 被塞了东西）。

物件一旦有了履历，它就能**反复回扣**，前后呼应，密度自然上来。

---

## 手法 2：一个动作写成「物理后果链」

不问「感觉怎么样」，问「**接下来物理上会发生什么**」。

示例链：`进去得太多 → 顶到什么 → 身体哪块被顶起来 → 外面能不能看见形状 → 那个人怎么反应`

- 差：`插入很深，她受不了了。`
- 好：`进得太深，小腹上被顶起一小块凸起，随即又跟着退下去，来回几次以后那块皮肤都红了。`

**关键**：每一步都是**新的事实**，不是把「很爽」换成四个形容词。
链条至少推三步，不要一步就跳到感受。

---

## 手法 3：敢写「不体面」的生理细节

AI 会绕开不好看的东西，但**越不体面越证明失控**。

可以放心用的清单：口水积在下巴、吞咽的声音、呛咳、干呕、眼泪把妆糊花、流到耳朵里、从鼻子里出来、发抖、抽筋、失禁、脚趾蜷起来、站不住蹲下去、衣服粘在身上。

**操作**：一场戏里至少放**一个**不体面的细节。不要美化它，就写它发生。

---

## 手法 4：借旁人的正常视角反衬

一直贴着当事人写，会写「局促」但写不出「荒诞」。要学会**拉远**。

结构：**先建立一个正常人的认知 → 再当场推翻它。**

- 餐厅侍者眼里这是一对恩爱情侣（他注意到男的给她剥虾）
- 然后切回来：桌子底下，她的脚正踩在什么上面，她脸上还带着笑

**操作**：长场景里插一段**不知情者的一两个念头**。用他的正常，反衬这件事有多不正常。

---

## 手法 5：内心独白必须「碎」

真实的心理活动**不成句**。它被打断、跳跃、重复、卡在同一个词上。

```
我…我怎么回事…
是他。
又来了！！
```

- 差：`她心中涌起复杂的情绪，既羞耻又难以言说。`（完整、通顺、有总结 → 假）
- 好：`不对。` / `等一下。` / `……他刚才是不是说过。` / `什么时候。`

**操作**：心理描写用**省略号 + 短句 + 重复**，允许语法不完整。
一次只写一个念头，写完就断。不要写「既有…又有…」。

---

## 手法 6：破折号与省略号各有专职，不通借

- `——` 只干两件事：**声音拖长**（`「不——」`）、**话被撞断**（`「我等——」`）
- `…` 干所有「断」的活：喘不上气、说不出、迟疑、失神、拖音

**铁律**：破折号**不能当插入语或逗号用**。
`她笑了——很勉强——然后走了` 是错的，改成 `她笑了，很勉强，然后走了`。

**比例参考**：参考长篇里破折号与省略号是 **1 : 20**（6.6 个 vs 133 个，每万字）。
AI 的输出经常反过来，破折号比省略号还多。

---

## 手法 7：短句是「重音」，不是「句式」

短句单独成段，是用来**砸节奏**的。一段长的之后跟一句四五个字的，力量全在那一下。

```
竟然就这样走了。

不是不想留下，是腿不听使唤。

退出来……又贴上去……再退出来……
```

**但短句极贵**：一段最多用一个，连着三个就成电报体了。
判断法：把两句话用逗号连起来读得通，就本来该连起来。

---

## 手法 8：比喻取自生活器物，不取自文学

- 差（二手、没画面）：`如同深潭`、`仿佛星辰`、`像被撕裂的丝绸`
- 好（能用眼睛验证）：`像骑马一样`、`像小孩把尿的姿势`、`像水闸`、`像个扶手`、`像塑料袋兜住水`、`像打桩机`

**取材清单**：厨房、车、五金、体育、宠物、机械、日常姿势。
**禁止取材**：其他小说里的现成比喻。那是三手货。

---

## 手法 9：用具体数字代替程度副词

- 差：`很久`、`很多`、`很深`、`好几次`
- 好：`第三管推不进去了`、`二十多分钟`、`一米六的人被折成两半`、`七八次`

数字自带**可信度和画面**。哪怕是假的、夸张的，也要给一个数。
`二十多厘米` 比 `非常巨大` 有力一百倍。

---

## 手法 10：时间用极简标记跳转

不要写过渡段。一个符号就切走。

```
几秒后

…………时间回到半年前…………

半小时后。

一个月以后。
```

**操作**：觉得需要写「与此同时」「时间流逝，很快就到了」的地方，全部删掉，换成一个时间戳或一条分割线。

## 手法 11：同一个动作，每次换一个变量

长篇不可能一直有新动作。**结构重复，变量更新**：

| 这次换什么 ||
|---|---|
| 场所 | 私密 → 半公共 → 公共 |
| 姿势 | 站 / 坐 / 跪 / 悬空 / 被抱 |
| 束缚 | 无 → 绳 → 固定 → 悬吊 |
| 观众 | 无人 → 旁观 → 不知情者 → 手机那头 |
| 道具 | 新增一件 |
| 状态 | 累 / 醉 / 忍 / 被打断 |
| 变量 | 外面有人 / 不能出声 / 时间不够 |

**操作**：写下一个场景前，先问「这次的变量是什么」。答不出来，就说明在重复。

## 手法 12：让身体和嘴打架

这类场景的核心引擎不是「想要」，是「**不要但身体要**」。

- 嘴上说停，腰自己在动
- 理智还在算账，膝盖已经软了
- 「不是不会反抗，是身体根本不听使唤」

**操作**：一场戏里至少一次 **语言/理智 与 身体反应相反**。
写这个反差时，两边都要写，不要只写身体，也不要只写心理。

---

## 手法 13：气味要分层，不是贴标签

气味有时间层：**新鲜的 / 闷过的 / 干涸的 / 重新被化开的**。

- 差：`有一股味道。`
- 好：`闷了一整天，汗干了又湿，那味道里带一点发酵过的甜。`

**操作**：气味跟着动作走，不是开头描写一次就完事。
被舔开、被弄湿、被风干，每次气味都该变。

---

## 手法 14：允许残缺（错字、语病、口语）

真人写东西不匀整。**完美的语法本身就是 AI 味。**

可以有的：口语倒装（`连我手都没碰过`）、省略主语、语气词（`嘛`、`啊`、`呗`）、一句话没说完、重复同一个词、标点不全。

**操作**：不要为了「正确」去修句子。念起来顺嘴比语法正确重要。
重复用同一个词是对的——**换同义词才是 AI 味**。

---

## 手法 15：让「日常」被侵蚀

不要只加一个场景进去，要让**日常动作本身变样**：

- 吃饭 → 吃别的东西
- 喝水 → 喝别的
- 道谢 → 谢的内容不对
- 汇报工作 → 一边被做什么一边汇报

**这是长篇能撑住的原因**：每个日常动作都变成了新的场景机会，不需要一直找新剧情。

**操作**：挑一个最平常的动作（穿衣、吃饭、洗澡、等车），把它整个替换掉。
