# 器官原名（全局硬规则）

> **这份是全局规则，不分题材、不分场景、不分是否色情。**
> 只要正文里出现身体部位，就适用这一条。
>
> 04（亲密场景）、07（足交）里关于「直白」的内容都指向这里，不在各自文件里重复维护。
> 写任何场景前，先过一遍这份；写完再做一次替换扫描。

---

## 一句话

**器官、体液、动作，一律直呼其名。一个代称都不留。**

不是「尽量用原名」，不是「多用一些」。是**零容忍**：
代称的破坏力**不按比例算，按出现算** —— 留一个就破一个画面。

实测过的失败：1600 字的稿子，具体名词用了 23 次，密度看着不错，
但残留 3 个「那里」+ 2 个「那个地方」，读者就在那 5 处掉了画面。

---

## 一、为什么这条最要命

`那里`、`那处`、`最敏感的地方` —— 这些词看起来「含蓄」「有文采」，实际效果是：

**读者不知道在写哪，画面直接消失。**

对比：

❌ `脚趾点在根部和旁边那一小片皮肤上，把最敏感的地方绕开。她能感觉到那里越来越硬。`
→ 四个代称连用，一句具体信息都没有。「那里」是哪？「硬」的是哪？

✅ `脚趾落在阴囊侧面，从下往上，绕开阴茎体，快到冠状沟就退回来。龟头顶端胀得发亮，马眼渗出来一点。`
→ 每一处都指得出位置。

**判据**：写完一句，问自己「读者能不能凭这句话在脑子里指出位置」。
指不出来，就是还在糊。

## 三、看到就删（禁用清单）

写完之后**逐个搜**，找到一个改一个。

| 禁用 | 通常是躲什么 | 改成 |
|---|---|---|
| 那里 / 那处 / 那个地方 / 那一处 | 任何部位 | 具体名词 |
| 最敏感的地方 / 敏感处 | 龟头 / 冠状沟 / 系带 / 阴蒂 | 直接点名 |
| 前端 / 顶端（单独用） | 龟头 | 龟头 |
| 底部 / 下边 / 深处（单独用） | 阴囊 / 睾丸 / 足心 / 宫口 | 直接点名 |
| 那道 / 那根 / 它 / 这东西 | 任何部位 | 具体名词 |
| 旁边的皮肤 / 一小片皮肤 / 那圈 | 阴囊 / 会阴 / 大腿根 | 直接点名 |
| 隐秘之处 / 私处（作名词用） | 任何部位 | 直接点名 |
| 有了反应 / 有了变化 | 具体是什么反应 | 写出来是什么变了 |

**允许保留的两个**：`根部`、`棒身` —— 指代明确，不算躲。

### 例外：方位用法不算代称

`那里` / `那处` 有两种用法，只有一种该禁：

| 用法 | 例 | 判断 |
|---|---|---|
| **方位词**（指空间位置） | `光从她肩窝那里斜过去` | ✅ 可以，它修饰的是「肩窝」这个已说出的部位 |
| **代称**（替代部位名） | `卡着的那处开了` | ❌ 应为 `卡着的阴道口开了` |

**判断法**：这个词**前后有没有出现具体部位名**？
- 前面刚说过部位 → 它只是补方位，留着
- 整句没有部位名，全靠它撑着 → 是代称，必须换

实测里就出过这个：一段 1200 字、22 个具体名词的稿子，最后搜出 2 个「那里/那处」，
其中 `光从她肩窝那里斜过去` 合格，`卡着的那处开了` 不合格（应为「阴道口」）。
**做替换扫描时不要机械全删，按这条判断。**

## 四、动词也会躲

不只名词，动作更容易写虚。

| 模糊动词 | 问题 | 改成 |
|---|---|---|
| 碰了碰 / 弄了一下 / 动作着 | 不知道做了什么 | 顶 / 碾 / 夹 / 蹭 + 对什么 |
| 在那里 / 在上面 | 没有方向 | 从哪到哪 |
| 使了点力 | 没有程度 | 压到什么程度、压出什么 |
| 感觉很明显 | 没有内容 | 谁感觉到了什么 |

**规则**：动作必须能指出**谁对谁做了什么**。

---

## 五、固定句式：施力方 + 动作 + 受力方

一个动作句要齐三样。**缺一样就会模糊。**

```
[手 / 指 / 脚趾 / 足弓 / 舌尖 / 腰] + [夹/按/推/碾/点/绕/卡/托] + [龟头/冠状沟/马眼/阴茎体/阴囊/睾丸...]
```

| 缺什么 | 后果 | 例 |
|---|---|---|
| 缺受力方 | 只知道有东西在动 | ❌ `脚趾轮流点着。` |
| 缺施力方 | 不知道是什么在碰 | ❌ `龟头被弄得很胀。` |
| 缺动作 | 两个名词并排 | ❌ `脚趾和龟头。` |
| **三样齐** | 能画出来 | ✅ `脚趾轮流点着龟头` |

**一段里不要连续三句都是同一个施力方。** 换着来。

## 六、同义词轮换也是代称

这是最像 AI 的习惯：怕重复，于是换个说法。

> 龟头 → 顶端 → 那个圆润的地方 → 前端

**四个词指同一个东西，读者要重新解码四次。**

参考文本的做法是**同一个词反复用**，最多那个用了 238 次。
**重复是人味，换词才是 AI 味。**

## 八、自检流程

**交付前按顺序做这三步：**

1. **搜禁用词** —— 用第三节的表逐个搜，命中就改
2. **查动作句** —— 每句问「谁对谁做了什么」，缺受力方的补上
3. **查同义词** —— 有没有为了「不重复」换了说法？换回去

做完之后再通读一遍，看画面在不在。
