# 硬指标与自检清单

> 数字是从真实中文网文里量出来的分布，不是感觉。
> 只在你需要「判断到底差在哪」或「交稿前过一遍」时读。

---

## 指标表

| 指标 | 目标 | AI 典型 |
|---|---|---|
| 段落长度中位数 | **40–55 字** | 80–150 字 |
| 30 字以内的短段占比 | **≥ 25%** | < 5% |
| 最长段落 | **≤ 200 字** | 常见 300+ |
| 段落长度差异 | 长短**剧烈交错** | 整齐均匀 |
| **平均句长** | **≥ 30 字** | 18 字左右 |
| **≥40 字的句子占比** | **≥ 20%** | 约 10% |
| **≥60 字的长句** | 每场至少 **3 句** | 0 句 |
| 10 字以内的碎句占比 | **≤ 30%** | 37% |
| 对话标签（说道/问道/开口道） | **几乎不用**，能不写就不写 | 每句都挂 |
| 比喻密度 | 每千字 **1–2 个** | 每段 1 个 |
| 「仿佛/宛如/似乎/瞬间/微微/缓缓」 | 每万字各 **≤ 5 次** | 每段 1 次 |
| 破折号 —— | **少**，500 字里最多 1 个 | 泛用 |
| 省略号 … | **多**，用于拖音与欲言又止 | 几乎不用 |

**句长是「生硬」的头号指标。** 平均句长低于 30 字，读起来一定是电报体。
不要用「切碎段落」去实现「有节奏」—— 段落可以短，**句子必须有长的**。
段落短 + 句子长 = 有节奏；段落短 + 句子也短 = 分镜脚本。

## 自检清单

**先数三项（这三项不过关，别的都白改）：**

- [ ] **平均句长 ≥ 30 字？** 数一下总字数 ÷ 句子数。低于 30 就是电报体
- [ ] **≥40 字的句子占到 20% 了吗？** 至少有 3 句
- [ ] **10 字以内的碎句多不多？** 超过 30% 就是分镜脚本，把相邻的短句用逗号并起来

**再看内容：**

- [ ] 最长段落超过 200 字了吗？（超了就切）
- [ ] 有三段长度几乎一样吗？（改成参差）
- [ ] 有没有直接写"她感到 XX"？（改成身体动作）
- [ ] 有没有 `说道` / `问道` / `开口道`？（删）
- [ ] 这段里形容词超过一个了吗？（删到只剩一个）
- [ ] 有没有出现「仿佛」或「似乎」？（能删就删）
- [ ] 破折号当逗号用了吗？（换成句号或省略号，500 字最多 1 个）
- [ ] 场景有具体时间/光线/声音吗？（补一处）
- [ ] 结尾是不是在总结升华？（删掉最后一句试试）
- [ ] 通读一遍，像人说话还是像写报告？

## 反例对照

**AI 味（整段都在解释）**

> 她的眼中闪过一丝复杂的情绪，仿佛有千言万语却难以言说。空气中弥漫着一丝微妙的尴尬，两人就这样静静地站着，时间仿佛在这一刻凝固了。

问题：`闪过一丝复杂的情绪`（解说不给内容）、`仿佛有千言万语`（比喻空转）、`空气中弥漫着尴尬`（抽象占位）、`时间仿佛凝固`（陈词）、四句全一样长。

**改后**

> 她张了张嘴。
> 没出声。
> 走廊尽头的灯管在响，滋滋的。
> 「……我先走了。」

同一件事，没有一个形容词，没有一个比喻，情绪全在动作和停顿里。
