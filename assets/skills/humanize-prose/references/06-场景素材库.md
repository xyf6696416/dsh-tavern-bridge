# 场景素材库

> 写具体场景时查这里。都是**可替换的原料**：体位、刺激部位、话术、配合方式。
>
> **⚠ 写足交场景请直接用 `07-足交专题.md`** —— 那里有足交专属的材质、部位、拟人化比喻和完整体位表。
> 这份只放**通用结构**（任何题材都能套的框架）。
>
> **⚠ 用到具体部位名时，遵守 `00-器官原名.md`**（全局规则，这里不重复）。
>
> 用法：先定「这次用哪个体位 + 打哪个部位 + 说哪一层话」，再动笔。
> **不要一次全用上。** 一场戏选 1 个体位 + 2 个部位 + 1 层话术就够。

---

## 一、体位库（通用结构）

任何体位都可以按这五个维度描述：**谁在什么高度 / 接触面是什么 / 谁控制节奏 / 视线在哪 / 有什么限制**。

| 类型 | 特点 | 适合 |
|---|---|---|
| **坐姿 / 躺姿** | 稳定，接触面大，能看清全身 | 初次、慢节奏、要看表情 |
| **跪姿 / 背向** | 有支配感，看不见对方表情 | 掌控、不确定感、背后视角 |
| **站立 / 半蹲** | 不稳，需要支撑，动态 | 公共、急促、时间紧 |
| **叠加 / 双人** | 多角度同时，需要配合 | 高级、要协调 |
| **借道具** | 材质改变触感，不只是换姿势 | 变化感、温差、阻力 |

**写体位时至少交代三样**：谁高谁低、身体哪几处接触、手在干什么。

**容易漏的**：重心在哪、哪里在支撑、有没有东西硌着、衣服卡在哪。

## 二、刺激部位（主攻 / 辅助 / 后备）

不要一上来就打最敏感的地方。**按耐受度排顺序**：

| 位置 | 特性 | 什么时候用 |
|---|---|---|
| **最敏感处** | 反应快、容易过载 | 初期轻碰、临界时逼 |
| **中段 / 面积大处** | 耐受高，可持续 | 相持段主力 |
| **周边 / 底部** | 积累型，不显眼但有效 | 铺垫、辅助、延长 |
| **背面 / 平时碰不到处** | 意外感强 | 用来打断节奏、制造突变 |

**转换逻辑**：
1. 一处的反应变弱了 → 换下一处
2. 快到临界 → 回到最敏感处
3. 需要拖时间 → 换到周边，慢慢来
4. 需要突变 → 突然换到平时不碰的地方

**关键**：每次换位置都要说清楚**为什么换**（看到什么了 / 想干什么）。

## 三、寸止的三种手段

寸止不等于「停下来」。有硬有软，三种可以叠。

| 手段 | 做法 | 效果 |
|---|---|---|
| **动作** | 停 / 减速 / 撤走 / 只留一点点接触 | 最直接，但用多了麻木 |
| **身体** | 压住、夹住、固定住，让对方没法自己动 | 剥夺主动性，屈辱感强 |
| **语言** | 明确禁止（「不准」「等一下」） | 心理压迫，配合前两种用 |

**恢复的时机**（这一步最容易被跳过）：
不是「过一会儿再继续」，而是**要一个具体的理由才恢复** ——
对方求了、对方安静下来了、对方说了某句话、或者主导方自己忍不住了。

**写恢复时把那个理由写出来。** 否则读者不知道为什么会继续。

## 四、话术的三层（按阶段推进）

同一场戏里，话要变。**一直用一层，会显得单调。**

| 层 | 阶段 | 特征 | 句式 |
|---|---|---|---|
| **挑逗** | 诱惑 / 相持 | 提问、留半句、撒娇 | 「想不想……」「你说呢」 |
| **羞辱** | 主导 / 折磨 | 贬低、对比、给人贴标签 | 「就这样？」「真没用」「你自己看看」 |
| **命令** | 满足前 | 短、祈使、不容置疑 | 「现在」「别动」「看着我」 |

**节奏**：挑逗 → 羞辱（配合寸止）→ 命令（放开前）→ 事后可以回软。

**三个要点**：
1. **话要短。** 长的台词在这种场景里最假。
2. **被打断。** 说到一半被动作打断，比说完更真实（`「你等——」`）。
3. **事后不一定回软。** 有时候冷着更真实，看人设。

**多人时**：一个唱红脸一个唱白脸（一个羞辱一个安抚），反差比合声更有压迫感。

## 五、多人配合（三个要点）

| 要点 | 做法 |
|---|---|
| **分工** | 一个控节奏，一个补位（补位的不抢主导） |
| **错开** | 一快一慢、一轻一重，**不要同步**（同步会变成齐奏，很假） |
| **换手** | 明确交代什么时候换：「这次换我」 |

**写多人最容易犯的错**：把两个人写成一个人重复两遍。
**解决**：给两个人不同的**风格**（一个话多一个不说话、一个急一个慢、一个看脸一个不看）。

## 六、环境与道具

### 环境要参与，不只是背景

- **声音**：能掩盖的（水声、车声、电视）→ 制造「不能出声」的张力
- **光线**：能看见多少 → 决定「看不看得清」
- **空间**：多窄、有没有退路 → 决定「能不能躲」
- **其他人**：会不会来、离多远 → 决定节奏快慢

**用法**：**外部动静直接改变节奏**。
有人靠近 → 放慢、压低声音；人走了 → 突然加速。这一下比任何形容词都有力。

### 道具要改变触感，不是只改变外观

| 道具 | 改变什么 | 怎么写 |
|---|---|---|
| 布料（丝 / 棉 / 网） | 摩擦系数、温度传导 | 干的时候什么样，湿了以后什么样 |
| 硬质（鞋、饰物） | 形状、阻力、声响 | 卡在哪、压出什么形状、发出什么声 |
| 液体（油、水、润滑） | 滑度、温度、声音 | 滴落的路径、被体温加热、干掉以后 |
| 束缚 | 剥夺自由度 | 勒痕、动不了的那一下、挣脱失败 |

**道具的「履历」**（见手法 1）：**用过的痕迹**比道具本身更有信息。
汗渍、磨损、残留、变形 —— 这些都是时间。
