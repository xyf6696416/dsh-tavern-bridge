# 情趣道具 —— 怎么写「身上带了东西」

道具场景的通病跟鞋袜场景一模一样：**只写道具名，不写道具本身。**
「她戴上了跳蛋」「他给她套上项圈」—— 这两句信息量为零。

道具是一类**特殊的名词**。它跟「杯子」「椅子」不同的地方在于：它会一直在她身上、一直起作用、一直有被别人发现的风险。
所以写道具，写的不是它长什么样，是**它让她变成了什么样**。

---

## 零、四条通病

**① 只写名字不写参数。**
道具的最小可写单位是三样：**尺寸 / 材质 / 固定方式**。缺一样就是模糊。
跳蛋不写大小（4cm 还是 7cm），读者不知道顶在哪个位置。
乳环不写直径（1.5cm），读者不知道它垂到哪儿。

**② 不写相对位置。**
道具是装在人身上的，它必须有一个**坐标**：乳头底部、包皮与阴蒂头之间、肛门口只露出圆头、左脚还是右脚。
没有坐标的道具是飘在空中的。

**③ 没有时间线。**
道具是有寿命的：**刚戴上 / 一直戴着 / 戴久了 / 取下来**，四段完全不同。
刚穿刺是刺痛，长期戴是充血；刚塞进去是异物感，戴久了拔出来肛门是张开的。
AI 只写中间那段「戴着」。

**④ 只有快感没有行为。**
这是最要命的一条，下面单列一节。

---

## 一、总纲：道具不提供快感，它改变行为

翻这批条目，每组「穿戴的影响」里，最有用的几句全都不在讲快感：

| 道具 | 原文写的「影响」 |
|---|---|
| 肛塞 | 不常用的人**行走时臀部动作不自然**；**坐下瞬间**因深入带来快感 |
| 气压假阳具鞋 | **步态变化**，会不自觉调整步伐；会**增加行走频率或故意踮脚** |
| 跳蛋 | 随着**行走、坐立**，位置轻微移动，带来不同刺激 |
| 连体衣 | 使穿戴者**更加意识到自己的身体轮廓**；公开场合**自我意识提升** |
| 假阳具口罩 | **呼吸需通过鼻子**；**说话能力受限或完全丧失** |
| 人体彩绘 | 胸部臀部**随运动而剧烈晃动**（这就是破绽） |

规律很清楚：**道具的第一个效果永远是姿势和动作变了，然后才是感觉。**

所以写道具场景，最省力的写法是：**先让她走两步。**

> 她走到门口，忽然想起自己下面塞着东西，脚就慢了半拍，
> 变成一小步一小步往前挪，膝盖微微并着。

这比「她感受到下体的充实」有效十倍。

**判据**：写完一段道具场景，如果删掉所有「快感」「刺激」「酥麻」这类词，场景还成立，就写对了；如果删完全空了，那就是在解说。

## 二、四步法

世界书每条都按这个骨架组织，照着填不会漏：

### 第一步：外观参数（能被看见的部分）
- **形状**：图钉状 / 椭圆 / C 形开口 / 心形 / 分节 / 螺旋
- **尺寸**：给具体数字或相对物（1.5cm 的环、4–7cm 的跳蛋、「特大蘑菇状」）
- **颜色**：银白 / 金黄 / 桃粉 / 漆黑 / 深紫带荧光
- **装饰**：铃铛、圆球、爱心吊坠、阴茎状吊坠、宝石
- **透明还是不透明**：这一条决定后面能看见什么（见第六节）

### 第二步：材质与触感（能被感觉到、有物理后果的部分）
材质不是形容词，是**因果链的起点**。

原文里最值钱的一条：
> 金属（银白色，**塞入时温度较低，导致肛门收缩分泌肠液**）

一句里三环：材质 → 温差 → 生理反应。这才是材质描写该有的样子。

| 材质 | 触感 | 后果 |
|---|---|---|
| 金属 | 凉、重、硬 | 插入瞬间低温 → 括约肌收缩、分泌；贴在皮肤上会压出痕 |
| 玻璃 | 光滑但冷，与液体接触生涩 | 刺激偏大，不适感明显 |
| 硅胶 / 橡胶 | 柔软、微微吸皮肤 | 插入顺畅，但久留会闷出汗 |
| 木材 | 温、钝 | 舒适，没有金属的锐利感 |
| 水晶 / 透明塑料 | 亮、轻、看得穿 | 内景外露（下面详述） |

### 第三步：行为变化（用动作写，不用感受写）
- 走路的样子（并腿、踮脚、小步、臀部不自然）
- 坐下的瞬间（会先顿一下、只坐半边、身体往前倾）
- 说话的方式（说不出来、只能发鼻音、句子变短）
- 手上在干什么（抓衣角、按住小腹、撑着桌沿）
- 表情控制（在忍、突然咬住嘴唇、眼神飘走）
- **对外部刺激的反应阈值变了**（声音大一点就抖）

### 第四步：快感构成（生理 + 心理两层，见下两节）

## 三、心理快感只有三层

把所有条目的「心理上」栏归类，翻来覆去就三种，认准是哪一种再写：

**第一层：被看见的风险。**
> 害怕人体彩绘被发现 / 在公共场合被迫忍耐 / 铃声使佩戴事实容易暴露 / 穿环被发现的潜在恐惧

关键词是**可能被看见**，不是已经看见。紧张感来自「还没发生」。
写这层要写：她怎么评估风险、怎么掩饰、掩饰得成不成功。

**第二层：被掌握的无力。**
> 生命权利被完全掌握的充实感 / 对控制者的绝对依赖 / 身体被完全掌控的屈辱 / 无法自行解除装置 / 生理反应不受控的焦虑

关键词是**她解不开**。这一层和道具的物理结构直接相关：有锁的、需要钥匙的、需要他人协助的、遥控在别人手上的，才配写这层。

**第三层：身份被改写。**
> 人类身份被毁灭的自毁感 / 获得母畜身份的满足感 / 性化身份成就带来的异样成就感 / 神圣哺乳器官被侵犯的背德感

关键词是**她已经不是原来的她**。胸牌上写着「便器母猪」而她引以为傲，这是最纯的第三层。

**注意**：第三层要用「物」承载，不能直接说。
不要说「她的尊严被摧毁了」，要说**她低头看胸牌，把翘起的一角按平了**。

**还有一件反直觉的**：项圈那条的「生理上」写的是「无」。
有的道具**完全不碰身体**，全靠身份工作。写作时别硬给它安排生理反应 —— 项圈的快感必须来自「脖子上有东西」这个事实本身，以及别人看她的眼神。

## 四、暴露渠道：紧张感的唯一来源

每件道具都有它**专属的泄露方式**，这就是场景张力的挂点：

| 道具 | 会怎么暴露 |
|---|---|
| 铃铛（乳环 / 阴蒂环 / 项圈） | **声音**。随肢体动作响，动作越大越响 |
| 跳蛋 | **声音**。安静环境里被周围人听见；也有水声 |
| 吸奶机 | **细小的水声**；收集瓶在衣服下鼓出一个形状 |
| 连体衣 | 面料**打湿或过度拉伸**时才透；乳头把面料顶出凸起 |
| 人体彩绘 | **体液让颜料褪色**（腋下、乳头、阴部）；运动时胸臀晃动 |
| 胸牌 | 衣领松了、弯腰时翻出来 |
| 假阳具口罩 | **口水**。堵着嘴，吞不下去，从下巴往下淌 |
| 乳钉 / 乳环 | 衣服薄时胸前两个凸点；碰一下会疼得抽气 |
| 锁链 / 一体式 | **走路时的金属声**；姿势被迫是挺胸张腿 |
| 肛塞 | 走路姿势不对，别人看得出「她坐得小心」 |

**写法**：把场景的紧张感全挂在一个具体渠道上，让这个渠道反复出现、越来越难控制。

> 第一次响的时候她停住，等了半分钟，确定走廊里没人。
> 后来她学会了一步一步挪，让两个环几乎不碰在一起。
> 可走到楼梯口，脚下的高度差让她不得不抬腿 —— 那一下响了两次。

这就是紧张感。整段没有一句「她很紧张」。

## 五、取下比戴上细

原文里最具体的描写全在「取下」这一侧，而不是「戴上」。这是个可以直接抄的规律 ——
**提取、揭开、拔出、脱下，是物理事件最密集的时刻。**

四条原文，全都比「戴上」具体：

- 肛塞：**拔出时会发出轻微的「啵」声**；带出粘滑肠液，**肛门微微张开**
- 乳贴：揭开后**冒出汗湿蒸汽**（因为透气性差）
- 阴贴：突然揭开会**扯掉几根阴毛**，使**阴唇抽搐**，分泌少量淫水
- 假阳具口罩：拔出时**带着唾液**，口腔有**短暂的空虚感和放松感**

**这四种写法值得记住，因为它们都是「身体在道具离开后的反应」：**
1. 声音（啵）
2. 带出物（肠液、唾液、汗汽）
3. 形状还没恢复（肛门张开、乳头还立着、被压出的红印）
4. 反向的空虚（拿掉之后更难受）

**「取下」还能当作场景的落点。** 结尾停在这儿，比停在高潮上更像人写的。

## 六、透明道具：把内景变外景

原文把肛塞分成两类，这一分类本身就是一个写作工具：

- **不透明**：只能看见露在外面的那个圆头装饰 → 描写重点在**装饰**
- **透明**：能直接看见肠道内部 → 描写重点在**肠壁和肛门的开合**

通则：**透明材质改变了叙事视角。** 平时看不见的东西被搬到外面来，读者从「感觉」切换到「观看」。

可以套用的地方：
- 透明肛塞 → 看见肠壁、看见肠液、看见括约肌一收一放
- 透明收集瓶 → 看见液面升高、看见颜色
- 透明口罩 → 看见嘴里塞着东西、看见唾液积在嘴角
- 玻璃假阳具 → 看见内部、也看见自己

**遮挡反而是强调**，这是最重要的一条反向用法：
- 阴贴贴上去，「**会完美展现阴唇阴阜轮廓**」
- 乳贴贴上去，「**乳头较大会把乳贴中间顶起**」「**乳晕较大乳贴不能完全覆盖**」
- 连体衣穿上，**骆驼趾、软肉轮廓、肛门形状和褶皱全都清楚**

所以写贴合类道具，别写「遮住了」，写**遮不住**。

## 七、分类索引

### 按功能分五类

**1. 穿刺类**（乳钉、乳环、乳链、阴蒂环）
有伤口、有恢复期、**是永久的**。写作抓手：刚穿刺的刺痛与不适应 vs 穿戴后长期充血勃起。
乳环是乳钉和乳链的**基础**，写的时候要交代层级关系（先有钉，才挂得上环，才拉得住链）。

**2. 贴合类**（乳贴、阴贴、胸牌）
贴上去的时候没什么，**摘下来的时候全是戏**（汗汽、扯毛、红印）。
另外：遮挡不严，反而是「她身体的具体形状」的展示器。

**3. 内置类**（肛塞、跳蛋）
体内、有声音、会随动作移位。写作抓手是**走路**。
跳蛋还多一层：**控制权在谁手上**（APP、声控、体感自动）—— 这一层直接决定能不能写「被掌握」。

**4. 外观改造类**（项圈、连体衣、人体彩绘、假阳具口罩）
靠**被别人看见**工作。核心是「她知道自己现在看起来是什么样」。
其中人体彩绘和连体衣是**以假乱真**路线：越像真的，越怕露馅，露馅的点极其具体。

**5. 装置类**（一体式锁链、气压假阳具鞋、吸奶机、触手衣物、异形假阳具）
**有机制、能自己动。** 写作要交代：动力从哪来（脚步气压、马达、生物本能、遥控）、
怎么调节（旋钮、APP、十级）、什么时候会突然变强。

### 按强度分四档（决定场景能放到什么场合）

- **日常级**：乳贴、阴贴、连体衣 — 出门能穿，只有她知道
- **隐藏级**：跳蛋、肛塞、气压鞋、吸奶机 — 出门能带，会有泄露风险
- **极限级**：穿刺、锁链、胸牌 — 不能见人，必须有遮盖或只有私下
- **幻想级**：触手衣物、异形假阳具 — 不需要物理可行性，需要**内部逻辑自洽**

**幻想级不是随便写。** 触手衣物的可信度来自「生物型 / 非生物型」的分野和「渐进侵蚀」的四阶段；异形假阳具的可信度来自六个系列各自的形状逻辑（触手是吸盘、龙是鳞片脊刺、虫是分节膨胀、马是蘑菇头）。

## 八、十八件速查

**乳钉** — 穿过乳头底部左右两端，两头圆头。银白 / 金黄 / 粉红。刚穿刺会刺痛；长期戴乳头充血勃起，衣服上顶出明显凸起；泌乳不畅、胸部肿。**是乳环和乳链的基础件。**

**乳环** — 直径约 1.5cm，最下方带装饰。铃铛（会响）/ 圆球 / 爱心吊坠 / 阴茎状吊坠。**随胸部运动大幅度摆动** —— 这个摆动本身就是描写。

**乳链** — 挂在两个乳钉或乳环之间。**短链把两个乳头往胸中央拽；长链在胸下前方垂出弧线。** 一短一长，两种完全不同的画面。

**阴蒂环** — C 形开口，套在阴蒂包皮与阴蒂头之间，开口可调松紧。初期异物感导致**行走时持续摩擦**；长期戴会轻微红肿。

**乳贴** — 覆盖乳头和乳晕的贴纸。粉 / 黑 / 白。**乳头大会把中间顶起来；乳晕大盖不全。** 透气性差，揭开冒汗汽。「fuck me！」白色字 X 形胶带 / 心形 / 圆环状（直接露乳头）。

**阴贴** — 心形，**尖端指向肛门方向**。贴上去反而把阴唇阴阜轮廓显出来。突然揭开扯掉几根阴毛、阴唇抽搐、渗一点淫水。

**胸牌** — 穿刺或夹子固定在**左乳**。除了身份信息，还写着性化成就业绩（「便器母猪」「精液上瘾」「痴女婊子」），**而她自己引以为傲**。心理三层的第三层，最纯的一件。

**肛塞** — 图钉状，尖端膨成圆头，只露圆头装饰（宝石、心形）。金属的**塞入时温度低 → 肛门收缩分泌肠液**；拔出发出轻微「啵」声；不常用的人**走路臀部动作不自然**，**坐下瞬间**深入。透明款能看见肠壁和肛门开合。

**跳蛋** — 4–7cm 长，2–4cm 宽，椭圆或球形。控制方式：APP 蓝牙 / 声控 / 体感反馈。六种震动模式（连续、脉冲、波浪、攀升、随机、自定义）。可带温感加热。**走动坐立会移位**，安静环境能听见。

**假阳具口罩** — 棉质不透明 / 透明款。内部硅胶假阳具插进口中当口塞。**唾液分泌增加、表面变湿滑；只能用鼻子呼吸；说不了话。** 摘下时带出唾液，口腔有空虚感。

**项圈** — 皮革卡扣，红 / 黑 / 白。狗牌（写个人信息）/ 铃铛 / 爱心 / 阴茎状吊坠。**生理快感栏是「无」** —— 靠身份和牵绳工作。

**连体衣** — 紧贴皮肤。**乳头把面料顶出凸起、胯下骆驼趾、小腹软肉轮廓、臀缝能看出肛门形状和褶皱。** 胸和胯下的面料可直接扯掉。打湿或过度拉伸才透。里面不能再穿任何东西。

**人体彩绘** — 在裸体上画衣服，乍看以假乱真。**破绽清单（直接可用的素材）**：胸臀随运动剧烈晃动、凸起的乳晕乳头、腰间软肉褶皱、阴毛、深邃臀缝、体液让颜料褪色（腋下、乳头、阴部）。

**一体式锁链** — 全套：乳环 + 金属项圈 + 阴蒂环 + **阴唇钩（两侧各三个，把小穴极限拉开）** + 尿道塞 + 肛塞 + 脚环，用锁链串起来。**牵一发而动全身**，强制挺胸微张腿的站姿。阴唇被拉开后**内部一览无遗**。这件是「被掌握」那一层的天花板。

**气压假阳具鞋** — 高跟鞋 + 假阳具，**踩踏产生气压驱动它膨胀收缩**。鞋侧旋钮调气压、鞋跟弹簧调张力。单脚模式（一脚踩一脚放）/ 双脚模式（同踩、同抬）。**改变步态**：变轻盈或变沉重、增加行走频率、故意踮脚、静止时重心移动也有细微变化。

**吸奶机** — 吸乳罩（医用硅胶，柔软透明）+ 泵体 + **透明收集瓶**。十级吸力，波浪 / 脉冲 / 持续三种模式，可授权他人远程控制。**透明瓶能看见液量和颜色** —— 这是它最强的视觉抓手。有细微水声，内置热敷。

**触手衣物** — 伪装成普通衣物。**生物型**：有自我意识，会感知情绪，需要精液补给，**会逼宿主去找男人**；**非生物型**：机械构造，遥控，伪装成缝线、装饰或衬里。侵蚀四阶段：几乎无感 → 细小触手伸出 → 增多增粗 → 高潮时衣面细微蠕动。**脱离后有戒断反应，身上留印记。**

**异形假阳具** — 六个系列，各有形状逻辑：触手型（深紫荧光、吸盘、自主蠕动）/ 龙族型（红金鳞片脊刺、龙头分叉、体温变色、鳞片竖起）/ 昆虫型（漆黑白甲壳、分节膨胀、顶端触角）/ 马型（巨大、**特大蘑菇头**、脉动波浪、喷射量三倍）/ 犬型（粉紫、**底部膨胀形成锁定**、锁定后持续脉动喷射）/ 猪型（粗短螺旋、**螺旋状射出**）。智能硅胶变温 + 仿生纤维蠕动 + 致感层微电流。

## 九、词的处理（跟 `00` 对齐）

世界书条目里用的是半口语词：**奶头、奶穴、奶子、小穴、菊穴、屁眼、屁穴、淫水**。

按 `00-器官原名.md` 的全局规则，正文里要落到解剖学原名：
- 奶头 / 奶穴 → **乳头、乳晕、乳房**
- 小穴 / 阴部 → **阴道、阴唇、阴阜、阴蒂**
- 菊穴 / 屁眼 / 屁穴 → **肛门、括约肌、肠道**
- 淫水 / 肠液 → **爱液、肠液**（这两个本来就是具体词，可以留）

**例外**：作为**道具名称**或**她自己的说法**时可以保留。
「便器母猪」是胸牌上印的字，原样写；她在心里说「奶头」也可以 —— 那是人物的用词习惯。
区别是：**旁白用原名，她的嘴可以用俗词。**

## 十、检查清单

写完一段道具场景，逐条过：

- [ ] 有没有写尺寸？读者知道它多大吗
- [ ] 有没有写它在身上的**具体坐标**
- [ ] 材质有没有引出至少一个物理后果（温度、摩擦、声音、压迫）
- [ ] **有没有写她的行为变了**（走路、坐下、说话、手放哪）—— 这条最重要
- [ ] 心理落在哪一层？被看见 / 被掌握 / 身份改写，是否明确是其中一种
- [ ] 紧张感有没有挂在**具体的暴露渠道**上（声音、颜色、形状、味道）
- [ ] 去掉所有「快感」「刺激」这类词，还成立吗
- [ ] 有没有取下的一刻？取下的声音、带出物、没恢复的形状、虚空
- [ ] 如果道具是透明的或贴合的，有没有用「遮不住」而不是「遮住了」
- [ ] 道具的**时间线**写到哪一段了（刚戴上 / 一直戴 / 戴久了 / 取下）

## 十一、最容易写错的样子

**① 把道具当形容词用。**
「她戴着一个性感的跳蛋走下楼」—— 道具变成了修饰语，等于没写。
道具必须是**主语或宾语**，它要自己产生动作。

**② 一次上全套。**
十八件一起戴，等于一件都没戴。一场戏**一件主道具 + 最多一件辅助**。
要让读者记住它，就得让它在场景里反复被提到、反复造成麻烦。

**③ 只写装置不写人。**
写气压鞋写了三百字机械原理，人物站在那里当展示架。
机制写三句就够，剩下的全给她被它弄成什么样。

**④ 忽略「她自己知不知道」。**
她知道和不知道，是完全两种戏。跳蛋在遥控里，她不知道下一秒会变强 —— 这是悬念；
她知道自己一走就会响 —— 这是自我管理。
写之前先决定：**这一场她知道多少？**

**⑤ 忘了道具会响。**
这批道具里超过一半会发出声音（铃铛、啵声、水声、金属声、震动声）。
**声音是道具场景里最便宜也最有效的紧张源** —— 因为它不依赖视觉，也就无法掩饰。

**⑥ 幻想级道具写成了无逻辑。**
触手衣物的可信度不在触手，在「它需要精液补给，所以会逼她去找人」这种内部规则。
越离谱的东西，越需要一条铁的规矩。
